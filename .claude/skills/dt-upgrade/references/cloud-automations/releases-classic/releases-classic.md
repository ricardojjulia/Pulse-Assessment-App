# Releases Classic

<!-- Jira: PRODUCT-9822 -->

**Gen3 replacement**: Ready-made release monitoring dashboard

**Phase 2 required**: no

## What changes

A ready-made release monitoring dashboard provides a flexible overview of the detected releases and utilizes dedicated SDLC events stored in Grail. Releases classic app (including issue tracker) will be deprecated and will show a teaser/guide to use the dashboard.

## Customer actions

- Update release tagging strategy
- Use workflows to fetch issues from 3rd party tools (such as Jira) as a successor of the classic issue tracker
