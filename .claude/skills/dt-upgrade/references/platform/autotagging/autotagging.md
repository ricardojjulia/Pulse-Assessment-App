# Autotagging

**Gen3 replacement**: Static tagging at source

**Phase 2 required**: no

## What changes

In many cases customers can meet use cases previously met by Autotagging by manually tagging the source of the data. Autotagging rules will be removed in Phase 3.

## Customer actions

- Customer must manually tag everything at the source
- Some use cases may require building complex pipeline rules
