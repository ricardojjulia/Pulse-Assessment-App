**Gen3 replacement**: Frontend health alerts

**Phase 2 required**: yes

## What changes

Configure recommended health alerts for monitored web and mobile frontends to automatically baseline errors and performance metrics. Create custom alerts for custom use cases (e.g., specific user action duration or dimension).

## Customer actions

- Enable health alerts per frontend monitored on Grail
- Disable equivalent alert on classic

## Tracking queries

Review alert configs created -- via alert management setting and filter for frontend.
