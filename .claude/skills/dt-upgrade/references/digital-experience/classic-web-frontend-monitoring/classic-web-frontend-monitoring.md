# Classic Web Frontend Monitoring

<!-- Jira: none -->

**Gen3 replacement**: RUM on the latest Dynatrace (Experience Vitals, Error Inspector, Users & Sessions)

**Phase 2 required**: yes (due to feature incompleteness)

## What changes

The next-generation Dynatrace Real User Monitoring (RUM) experience, powered by Grail and DQL, delivers unified, actionable insights across modern web and mobile applications.

## Customer actions

- Enable new RUM on existing frontends
- Update instrumentation if necessary (agentless)

## Tracking queries

Check Experience Vitals inside the customer tenant and review list/share of enabled frontends (filter by web).
