# Query User Sessions (USQL)

**Gen3 replacement**: DQL

## What changes

DQL is a much more powerful query language than the RUM-specific USQL. Together with the evolution in RUM data collection and the capability to operate on `user.sessions` and `user.events` data sets, more use cases are possible.

## Customer actions

- Upgrade classic dashboards and move tiles from USQL to DQL
