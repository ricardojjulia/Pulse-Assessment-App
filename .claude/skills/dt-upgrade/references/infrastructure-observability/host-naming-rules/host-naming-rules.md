# Host Naming Rules

<!-- Jira: PRODUCT-13896 -->

**Gen3 replacement**: Naming at source

**Phase 2 required**: no

## What changes

Host naming rules are not supported by RCM. Customer must set host names manually.

## Customer actions

- Set host names manually at the source

## Tracking queries

If rules are enabled in `builtin:naming.hosts`, customer needs to upgrade. Note: this is not a Settings 2.0 schema.
