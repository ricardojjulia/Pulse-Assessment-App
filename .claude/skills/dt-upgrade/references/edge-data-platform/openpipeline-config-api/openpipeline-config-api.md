# OpenPipeline Config API

<!-- Jira: none -->

**Gen3 replacement**: Settings API

**Phase 2 required**: no

## What changes

Users must opt-in to using the Settings API for OpenPipeline configuration, which will break all existing config-as-code setups that use the old API.

## Customer actions

- Click the opt-in button to switch to Settings API
- Update all automation and config-as-code tooling to use the new Settings API endpoints
